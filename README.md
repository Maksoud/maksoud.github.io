# Notas de Estudo

Notas pessoais de estudo sobre carreira, gestão de projetos, dados, IA, finanças, desenvolvimento web e outros temas, escritas em Markdown no [Obsidian](https://obsidian.md).

📖 **Leia as notas em:** [correiarodrigues.com.br/notas](https://correiarodrigues.com.br/notas/)
🌐 **Site:** [correiarodrigues.com.br](https://correiarodrigues.com.br/)

## Como funciona

1. Escrevo e organizo as notas no Obsidian, dentro desta pasta.
2. O `save.bat` envia as alterações para este repositório (`git add`, `commit` e `push`).
3. O site [correiarodrigues.com.br](https://correiarodrigues.com.br/notas/) publica as notas a partir daqui.

O índice completo está no [Sumário](Sumário.md) e as dicas de formatação em [Markdown Instructions](Markdown%20Instructions.md).
