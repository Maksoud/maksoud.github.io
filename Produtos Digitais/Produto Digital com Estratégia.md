Capítulos sugeridos (40-50 páginas total):

- Introdução: Por que finanças pessoais falha
- Cap 1: Visão geral do sistema de controle (conceitual)
- Cap 2: Passo-a-passo: suas primeiras transações
- Cap 3: Relatórios e insights automáticos
- Cap 4: Planejamento financeiro com dados reais
- Conclusão: Próximos passos (upsell suave para SaaS)

**Design e publicação** (Semana 2-3):

- Capa + formatação em Canva (30 min)
- PDF compilado (você já sabe fazer isso)
- Upload em Kiwify (15 min configuração)
- Preço: **R$ 97** (psicológico, não R$ 67)

**Marketing** (Semana 3-4, ongoing):

- Tweet a cada 2 dias com insight do e-book
- Email para contatos antigos (colegas, ex-clientes)
- Post em grupos de TI/Finanças no LinkedIn
- **Não gaste tempo em funil complicado.** Simples = conversão mais rápida.
- Meta mínima: 50 vendas = **R$ 4,850** bruto

**Upsell para SaaS** (automático após compra):

- E-mail automático no Kiwify: "Gostou? Veja a versão full"
- Landing page do SaaS link no e-book
- Taxa de conversão conservadora: 10% = 5 clientes em potencial (não garantido, mas possível)

- **Posicionamento** (Semana 1):
    - Defina personas: "Freelancers que querem controle financeiro automático" ou "Pequenas empresas de TI"?
    - Não tente vender para todos. Foco = conversão.
    - Posicione como **"Alternativa brasileira a ferramentas caras"** (não "clone do Xero"). Diferenciador: controle local, integração com banco brasileiro, relatórios em português.
- **Landing page + MVP** (Semana 2):
    - Crie uma landing page simples em HTML (ou use Gamma da Anthropic)
    - **Mostre screenshots reais do seu sistema** com dados ofuscados
    - CTA único: "Agendar demo gratuita"
    - Link para Calendly (15 minutos de demo)
- **Funil de prospecção** (Semana 3 onwards, paralelo):
    - Mensagem direta no LinkedIn: "Ouvi que você trabalha com finanças. Temos uma solução lean para controle. Quer ver?"
    - Target: proprietários de pequenas software houses, freelancers com 5+ anos, ex-colegas que empreenderam
    - Foco: 5-10 mensagens por dia = alta probabilidade de 1-2 demos por semana
    - Conversão esperada: 1 demo em 3 = ~30% closing = 1 cliente de 3 demos
- **Modelo de negócio**:
    - **Preço**: R$ 500-800/mês para "Plano Essencial" (3-5 usuários, 3 contas bancárias, relatórios ilimitados)
    - **Contrato anual com desconto** (2 meses grátis) = R$ 4,800-7,200/cliente/ano
    - **Lifetime value por cliente**: R$ 24k-36k em 3 anos
    - Meta conservadora: 3 clientes em 8 semanas = **R$ 1,500-2,400/mês**
- **Diferenciadores rápidos para destacar**:
    - Integração com OFX/REST de bancos brasileiros (seu sistema já faz isso?)
    - Relatório automático por email a cada semana
    - Backup automático na nuvem
    - Suporte via WhatsApp (pessoal, você responde direto)
